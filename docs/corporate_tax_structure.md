## 一、法人架构

```
┌─────────────────────────────────────┐
│          香港总部（HQ）              │
│     Herix International Ltd.        │
│  · 品牌持有 / IP 注册               │
│  · 全球账单主体                      │
│  · 对外融资主体                      │
└──────────┬──────────────────────────┘
           │ 全资控股
    ┌──────┴──────────────┐
    │                     │
┌───┴───────┐      ┌──────┴────────┐
│  日本子公司 │      │  中国子公司   │
│ 合同会社   │      │ WFOE / 外企   │
│ · 日本品牌  │      │ · 中国品牌    │
│ · 日本赫使  │      │ · 中国赫使    │
└────────────┘      └───────────────┘
```

**香港选择原因：**
- 企业所得税 8.25%（前 HKD 2M）/ 16.5%（以上）
- 境外收入免税（territorial tax system）
- 对外支付无预提税（股息 / 特许权使用费）
- 国际银行开户友好，USD/CNY/JPY 多币种账户

## 三、资金流向

### 3.1 品牌充值（Inbound）

```
日本品牌 ──充值──→ 日本子公司
中国品牌 ──充值──→ 中国子公司
国际品牌 ──充值──→ 香港 HQ
```

### 3.2 赫使报酬（Outbound）

```
赫使居住地       付款主体          税务处理
─────────────────────────────────────────────
日本居住赫使  ←  日本子公司      源泉徴収 20.42%（若适用）
中国居住赫使  ←  香港 HQ        无日本代扣；赫使自行申报中国个税
其他海外赫使  ←  香港 HQ        无日本/中国代扣；赫使自行申报所在国
```

### 3.3 实体间结算（Inter-company）

```
日本子公司 ──管理费/品牌使用费──→ 香港 HQ
中国子公司 ──管理服务费────────→ 香港 HQ
```

实体间结算必须签订**书面服务协议**，定价需符合独立交易原则（arm's length）。

## 四、税务处理细则

### 4.1 日本子公司

| 场景 | 税率 | 备注 |
|------|------|------|
| 企业所得税 | 约 23.2%（法人税＋地方税） | 正常经营利润 |
| 向香港 HQ 支付管理费 | 无预提税（日港协定） | 需合理定价 |
| 向海外赫使付款（境外服务） | 无需扣税 | 服务在日本境外履行 |
| 向日本居住赫使付款 | 源泉徴収 20.42% | 以日本银行账户收款为判断依据 |
| 支払調書 | 年收 ¥50,000 超须申报 | 每年 1 月 31 日前提交 |

### 4.2 中国子公司

| 场景 | 税率 | 备注 |
|------|------|------|
| 企业所得税 | 25%（一般）/ 15%（高新技术） | 视认定情况 |
| 增值税（服务费收入） | 6% | 现代服务业 |
| 向香港 HQ 支付服务费 | 预提税 5%（中港税约） | 股息 5%，特许权 5% |
| 向中国赫使付款 | 劳务报酬代扣 20%~40% | 依金额适用税率 |

### 4.3 香港 HQ

| 场景 | 税率 | 备注 |
|------|------|------|
| 企业所得税（境外收入） | 0% | 香港属地原则 |
| 企业所得税（香港源收入） | 8.25% / 16.5% | 分档 |
| 向海外赫使付款 | 无预提税 | 香港无预提税制度 |
| 股息汇出给股东 | 无预提税 | 香港优势之一 |

## 五、赫使居住地判定规则

由于服务在互联网上交付，无法直接核实赫使物理位置。

**判定流程：**

```
入驻申报地址 = 日本  OR  收款账户 = 日本银行账户
    → 视为日本居住者 → 日本子公司付款 → 扣税 20.42%

入驻申报地址 = 海外  AND  收款 = 海外账户（支付宝/微信/Wise/境外银行）
    → 视为非居住者 → 香港 HQ 付款 → 不扣税
```

**合规保护措施：**  
入驻协议中赫使需签署声明：

> "本人确认税务居住地为 [国家/地区]，若申报不实，由此产生的税务责任由本人承担。"

此声明使 Herix 成为"善意付款方"，若赫使虚报居住地，责任转移至赫使本人。
